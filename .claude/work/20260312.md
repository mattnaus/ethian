## Mailbox filter dropdown not opening — `7f03519`

**Request:** Mailbox filter dropdown still not opening when clicked, despite previous nested-component fix.

**Plan:** Fetched v0 prototype source. Key difference found: v0 uses `filterOpenDesktop` and `filterOpenMobile` as separate state variables. Ethian was sharing a single `filterOpen` for both desktop and mobile Popovers. Radix manages focus trapping and outside-click detection for every `open={true}` Popover instance, including CSS-hidden ones. With shared state, clicking the desktop trigger made both Popovers "open" simultaneously — the hidden mobile Popover's outside-click handler then fired and immediately closed the dropdown. Fix: split into two independent state variables.

**Changes:**
- `src/app/(app)/inbox/_components/inbox-view.tsx` — replaced `filterOpen`/`setFilterOpen` with `filterOpenDesktop`/`setFilterOpenDesktop` and `filterOpenMobile`/`setFilterOpenMobile`; each Popover now uses its own state
