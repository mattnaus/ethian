## Account color picker — `9ac16b0`

**Request:** Each mail account should have a color for UI identification. When adding a new account, a random color is picked as default; the user can overwrite it by selecting from a palette.

**Plan:** Add `color` column (text, not null, default `#3b82f6`) to `mail_accounts`. Wire it through the Zod schema and both add/update Server Actions. Add a row of 8 colored swatches to the account form (random default on add, existing value on edit). Show a small colored dot in the accounts list.

**Changes:**
