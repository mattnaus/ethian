## i18n: next-intl translation infrastructure — `ec7ccd8`

**Request:** Make the application translation-ready without URL-based locale routing.

**Plan:** Install next-intl v4 with `localePrefix: 'never'`. Extract all ~120 hardcoded UI strings into `messages/en.json`. **Changes:**
- `messages/en.json` — all English strings organized by namespace (auth, nav, settings, pages, colors)
