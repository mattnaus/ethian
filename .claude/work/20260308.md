## Initial project scaffold

**Request:** Build a self-hosted, open-source email client called Ethian, inspired by Hey.com. Stack: Next.js 15 App Router, TypeScript, shadcn/ui + Tailwind v4, PostgreSQL + Drizzle ORM, imapflow, nodemailer, BullMQ + Redis.
